# H/F Sonora — sitio web

El sitio de **Hackers/Founders Sonora**, el meetup mensual de startups en Hermosillo. Parte de [Hackers/Founders](https://hf.cx/).

- **Stack:** [Astro](https://astro.build) (sitio estático) + Hostinger (hackersfounders.mx)
- **Diseño:** [`DESIGN.md`](DESIGN.md)
- **Reglas para agentes de IA:** [`AGENTS.md`](AGENTS.md)
- **Cómo contribuir:** [`CONTRIBUTING.md`](CONTRIBUTING.md)
- **Buenas prácticas (explicadas sin jerga):** [`docs/GOOD-PRACTICES.md`](docs/GOOD-PRACTICES.md)

## Correr el sitio en tu compu

```bash
npm ci
npm run dev
```

Abre http://localhost:4321.

## Agregar un meetup

Ver "How to add a meetup" en [`AGENTS.md`](AGENTS.md). O abre un issue con la plantilla **Nuevo evento** y alguien (o el agente) lo hace.
